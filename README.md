# Block Breakers Incremental

> [!WARNING]  
> Some assets have been omited from this repo to comply with the licenses of some assets used in this game.
> All code is included in this repo.

## Description
Block Breakers Incremental is a highly satisfying progressive incremental inspired by Atari Breakout.
Break blocks to earn coins to purchase upgrades and buy cards that unlock unique abilities and passives to earn more coins.
